
# 上传 GitHub

建议仓库名：`codex-wechat-session-manager`

建议简介：Windows 上通过官方微信 iLink 管理和继续本机 Codex 会话，支持文件回传。

在 GitHub 新建仓库后，上传这个文件夹**里面的文件和子目录**，让 `README.md` 位于仓库根目录，不要只上传 ZIP，也不要额外套一层文件夹。上传时包含 `.gitignore` 和 `.gitattributes`。

文件夹已经按公开展示用途整理：源码、演示截图、验证说明、构建脚本、空凭据样例、AGPL 许可和来源说明。没有带入个人配置、真实聊天记录、登录二维码、日志、备份或旧版 EXE。

以后运行程序产生的私有配置、日志、备份、`work/`、`dist/`、`.venv/` 和缓存不属于作品展示材料。使用网页上传时 `.gitignore` 不会替你过滤文件，仍应选择当前整理好的材料。

若上传构建出的 EXE，建议放 GitHub Releases，并提供对应源代码与许可。请保留 `NOTICE.md`，不要把上游通信代码写成全部原创，也不要声称获得微信或 OpenAI 官方背书。
